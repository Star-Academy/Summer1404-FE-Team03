About This Project

A modern book collection manager built with Angular and Signals.

Project Goal

This application was developed as a part of the CodeStar Phase 6 program. The primary goal was to build a full CRUD (Create, Read, Update, Delete) application using the latest features of Angular, including Standalone Components and the new Signals-based state management system.
